# Hearth Launcher — подготовиться и войти в мир

[English](launcher.en.md) · [К панели](../README.md)

Лаунчер сохраняет ваши серверы, проверяет установленный набор модов и запускает Valheim через Steam. Он получает сборку с сайта выбранного сервера Hearth: при смене модов администратором игроку достаточно снова нажать **«Играть»**.

## Первый запуск

1. Установите Valheim в Steam. Для Linux выберите **Windows-версию игры через Proton**.
2. Скачайте лаунчер с лендинга сервера. В Windows откройте `Hearth-Launcher.exe`. На Linux распакуйте `Hearth-Launcher-Linux.tar.gz` и запустите `Hearth-Launcher` из полученного каталога.
3. Выберите найденную папку Valheim или укажите её вручную. В ней должны находиться `valheim.exe` и `valheim_Data`.
4. Добавьте **HTTPS-адрес сайта Hearth**, например `https://loki.ach-play.ru`, и сохраните профиль. Нужен адрес сайта без дополнительного пути, с обычным HTTPS-портом 443.
5. Нажмите **«Проверить сборку»**, затем **«Играть»**. Перед заменой модов закройте игру.

Готовые сборки содержат .NET и интерфейс лаунчера; отдельно ставить SDK, Python или .NET не требуется. Поддерживаются Windows x64 и настольный Linux x64 со Steam или Steam Flatpak. На Linux необходимы обычные графические библиотеки рабочего стола; Wayland использует XWayland.

## Linux и Proton

Один раз откройте в Steam **Valheim → Свойства → Совместимость** и включите Proton. Для сервера с модами в **Общие → Параметры запуска** добавьте:

```text
WINEDLLOVERRIDES="winhttp=n,b" %command%
```

Если уже используете параметры, сохраните их. Добавьте `winhttp=n,b` в имеющееся значение `WINEDLLOVERRIDES` через точку с запятой; `%command%` должен остаться один раз. Например:

```text
WINEDLLOVERRIDES="winhttp=n,b" gamemoderun %command%
```

Та же настройка нужна в Steam Flatpak. Лаунчер показывает инструкцию и позволяет скопировать параметр; настройки Steam сохраняете вы. Для ванильного запуска поддерживаемый загрузчик Doorstop отключается параметром только на этот запуск.

## Что происходит при нажатии «Играть»

Лаунчер читает режим, версии и клиентскую сборку выбранного сервера. Для V+ используется именно установленная на сервере версия Grantapher, для BepInEx — опубликованный сервером клиентский набор. Включённые серверные моды без клиентской области в набор не попадают.

Если состав и контрольные суммы файлов совпадают, повторная загрузка и установка пропускаются. При новой сборке скачивается её ZIP; проверенные архивы сохраняются в кеше. Повреждённые или недостающие файлы восстанавливаются из проверенного архива, а при изменении состава заменяются только отличающиеся файлы. Это кеширование готовых архивов, а не загрузка отдельных модов из каталогов.

Перед изменениями создаётся копия заменяемых файлов. Лаунчер повторно сверяет сборку с сервером: если администратор успел её поменять во время скачивания, установка отменяется. При ошибке предусмотрен откат. Текущие конфиги в `BepInEx/config` сохраняются.

После проверки запускается Steam с Valheim. При включённом **«Подключиться к выбранному серверу»** передаётся опубликованный адрес `host:port`; при необходимости его можно переопределить в профиле. Выбор персонажа и пароль остаются в игре. Пароль не требуется вводить в лаунчер и не публикуется через API. Если игра не перешла к подключению, скопируйте адрес из лаунчера и используйте **«Присоединиться → по IP»**.

Саму игру обновляет Steam. Лаунчер показывает требуемую сервером версию; если локальную версию нельзя определить надёжно, интерфейс прямо сообщает об этом. Проверьте её в меню Valheim перед входом.

## Несколько серверов и ванильный режим

Профиль сохраняет имя, сайт сервера, папку игры и при необходимости адрес подключения. Домены не привязаны к Loki: можно добавить любой сервер Hearth с публичным HTTPS-сайтом.

При использовании одной папки игры профили переключают управляемый набор модов, а конфигурации остаются общими. Профиль не является отдельной копией Valheim. Сторонние DLL, не принадлежащие лаунчеру, сохраняются и отмечаются в предупреждениях о совместимости.

Для ванильного сервера моды не скачиваются и не устанавливаются. Поддерживаемый Doorstop 3/4 отключается для запуска; файлы модов сохраняются. Если загрузчик неизвестен, лаунчер не пытается угадывать безопасный способ отключения. Нестандартные нативные модификации требуют отдельной проверки.

## Восстановление и настройки

**«Восстановить копию»** отменяет последнюю установку лаунчера в выбранной папке и возвращает сведения о прежнем наборе. Изменённые после установки файлы автоматически не перезаписываются: сообщение подскажет, какой файл нужно проверить. Копии старых установщиков Loki хранятся отдельно.

Профили, выбранный язык и кеш находятся в локальном каталоге HearthLauncher. Набор и копии файлов игры хранятся в её `.hearth-launcher`. Переключатель **RU / EN** меняет язык сразу и сохраняет ввод. Кнопки сайта и сообщества берут ссылки выбранного сервера.

Запуск и подключение через настоящий Steam/Proton требуют проверки в игре: автоматические проверки используют временные файлы, демонстрационные сборки и планы запуска, без выполнения игровых DLL.
