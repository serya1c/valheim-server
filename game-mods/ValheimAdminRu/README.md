# Админ-панель Valheim — RU / EN

Версия мода: **0.4.0**. Поддерживаемые версии игры: **1.0.16 и 1.0.17**. Сетевой протокол: **4**. Мод рассчитан на выделенный сервер. Одна и та же DLL устанавливается на сервер и **всем клиентам**.

При обновлении с предыдущих версий замените DLL **на сервере и у всех клиентов** перед повторным подключением: мод проверяет совпадение версий. На всех сторонах должна быть версия мода **0.4.0**. Версия самой Valheim также должна совпадать у сервера и подключающегося клиента. Конфигурацию и `adminlist.txt` можно сохранить.

## Язык интерфейса / Interface language

Кнопки **RU / EN** вверху меню **F8** переключают вкладки, подсказки, подтверждения, каталог предметов/существ и сообщения сразу. Введённые значения, выбранные объекты и сохранённые точки остаются на месте. Последнее сообщение переводится заново из исходного текста; язык сервера и других игроков не меняется.

Выбор сохраняется на вашем компьютере в `BepInEx/config/ru.valheim.adminpanel.cfg`: секция `[Интерфейс]`, новый ключ `Язык = ru` или `Язык = en`. Существующие русские секции и ключи конфигурации сохранены. Имена игроков, причины блокировок, названия ваших точек и prefab ID не переводятся. Переключатель относится к этому моду, а не ко всему Valheim. Для стороннего объекта без нужного перевода показывается доступное название автора или ID. Исходные серверные журналы сохраняют русский текст; при просмотре в меню переводятся системные подписи и результаты.

The **RU / EN** buttons at the top of the **F8** menu switch tabs, help text, confirmations, the item/creature catalog, and messages immediately. Drafts, selected objects, and saved waypoints are preserved. The latest message is translated from its original source; each client chooses a language independently.

The choice is stored locally in `BepInEx/config/ru.valheim.adminpanel.cfg`, under `[Интерфейс]`, as `Язык = ru` or `Язык = en`. Existing Russian configuration keys are unchanged. Player names, ban reasons, custom waypoint names, and prefab IDs remain literal. This switch does not change Valheim's own language. Third-party objects without a translation retain their available author-provided label or ID. Server audit files retain Russian source text; the menu translates system labels and results when displaying them.

Проверка переводчика без игры / Standalone locale checks (requires .NET 10 SDK):

```bash
dotnet run --project tests/LocaleTests.csproj -c Release
```

В версии **0.3.1** по умолчанию скрыта подпись «Этот предмет был получен с помощью читов» в описании предметов, включая уже созданные вещи. Изменяется только отображение: метки предметов и учёт достижений игры сохраняются. Вернуть подпись можно в `BepInEx/config/ru.valheim.adminpanel.cfg`: секция `[Интерфейс]`, параметр `СкрыватьНадписьОЧитах = false`. После изменения файла перезапустите игру.

Реализованы все запрошенные действия:

- Телепорт на выбранную точку большой карты.
- Телепорт к игроку из списка, включая игроков со скрытой позицией на карте.
- Телепорт выбранного игрока к администратору.
- Включение и выключение бессмертия себе или выбранному игроку.
- Создание предметов из игрового списка с поиском по русскому названию и ID.
- Создание мобов и боссов из игрового списка с таким же поиском.
- Выравнивание земли вокруг себя с выбором радиуса и показом площади.
- Подъём и опускание земли на выбранную высоту в заданном радиусе, с сохранением формы поверхности.
- Полёт для своего персонажа с включением и выключением в панели.
- Отдельный «Супермолот администратора»: удар по площади с базовым уроном **999999** мобам, деревьям, руде и постройкам. Игроки исключены из целей этого удара.

В версии **0.3.0** добавлены:

1. Отдельные группы целей супермолота: мобы, деревья, руда и постройки.
2. Предпросмотр области изменения рельефа, удара молота и ремонта.
3. Отмена последнего изменения земли в текущем подключении с сохранением более поздних правок.
4. Удаление последней порции собственного административного спавна в текущем мире.
5. Именованные точки отдельно для каждого мира и возврат после телепорта.
6. Лечение выбранного игрока, восстановление выносливости и снятие известных вредных эффектов.
7. Режим строительства без ресурсов и износа строительных инструментов, а также ремонт построек в радиусе.
8. Отключение, блокировка с причиной и снятие блокировки, включая игроков вне сети.
9. Серверные роли владельца, модератора и строителя с отдельными наборами прав.
10. Серверный журнал действий с поиском по администратору и действию.

**Установка**

1. Полностью остановите сервер и закройте игру перед установкой.
2. Установите [BepInExPack для Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/) на сервер и компьютеры игроков. Для Linux сервер запускается через скрипт BepInEx из этого пакета; подробности приведены на странице пакета.
3. Скопируйте папку `BepInEx` из этого архива в корневую папку сервера. Получится:

   ```text
   BepInEx/plugins/ValheimAdminRu/ValheimAdminRu.dll
   ```

4. Скопируйте эту же папку в установленную игру каждого игрока. При использовании менеджера модов копируйте её в папку профиля, из которого запускается игра.
5. Добавьте ID администраторов в **серверный** `adminlist.txt`, по одному ID на строку. Для Steam можно использовать SteamID64. Пример с условным ID:

   ```text
   76561198000000000
   ```

   Файл находится в каталоге сохранений сервера; при запуске с `-savedir` используется указанный каталог. Для других платформ используйте полный ID в формате, который принимает сам Valheim.
6. Запустите сервер и клиентов. После подключения нажмите **F8**. В верхней части панели появятся роль и сообщение о правах, подтверждённых сервером.

Обычным игрокам запись в `adminlist.txt` не нужна. Они устанавливают DLL, чтобы получать команды призыва, бессмертия и помощи и видеть новый предмет. Установленная DLL сама по себе не даёт административных прав. Для призыва, бессмертия, лечения, восстановления выносливости и снятия эффектов мод должен быть установлен у выбранного игрока. Телепорт администратора к игроку доступен и без мода у выбранной цели.

**Роли и права**

Сервер проверяет права при каждой команде. Участники серверного `adminlist.txt` всегда получают роль **«Владелец» (Owner)** и полный доступ. Их права защищены от изменения через панель.

| Роль | Доступ |
|---|---|
| Владелец — Owner | Все действия, включая назначение ролей |
| Модератор — Moderator | Телепорты, полёт, помощь игрокам, модерация и журнал |
| Строитель — Builder | Телепорты, полёт, создание объектов, рельеф, супермолот, строительство, ремонт и журнал |
| Игрок — None | Административные права не назначены |

Только владелец может выбрать подключённого игрока на вкладке «Игроки» и назначить ему роль «Модератор» или «Строитель». Кнопка «Игрок» снимает выданную роль. Изменение собственной роли и назначение владельца через панель недоступны: владельцев добавляют в `adminlist.txt` сервера. Дополнительные роли сохраняются на сервере в `BepInEx/config/ValheimAdminRu/roles.xml`.

Модератор не может отключить или заблокировать другого модератора. Владельцы защищены от отключения и блокировки через мод. Назначение ролей и модерация работают с подключёнными игроками независимо от состояния их персонажа; получение игровой помощи требует живого загруженного персонажа и установленного мода.

**Установка и обновление через Hearth**

В актуальной панели откройте «Моды» и установите встроенный **Hearth Admin**. Панель устанавливает его на сервер и включает в клиентский набор; игрокам нужно обновить набор и перезапустить игру. Встроенный архив `app/builtin-mods/ValheimAdminRu.zip` создаётся из собранной DLL командой `python game-mods/ValheimAdminRu/package.py` из корня репозитория. Библиотеки Valheim и BepInEx в этот архив не входят.

Файловый мост включается только на выделенном сервере, когда Hearth автоматически передаёт игровому процессу `HEARTH_ADMIN_BRIDGE`. На клиенте переменную задавать не нужно. Каталог `/data/admin-bridge` закрыт от публичной загрузки и не включается в игровые резервные копии; команды привязаны к текущей сессии и имеют срок действия.

При переходе с ручной установки сначала удалите прежнюю `ValheimAdminRu.dll` из активного выпуска, чтобы не загрузить два экземпляра мода. Следующая инструкция относится к прежней ручной установке; для управляемого встроенного пакета используйте раздел «Моды».

**Ручное обновление в прежней установке Hearth с Valheim+**

Остановите игровой сервер кнопкой в Hearth, оставив сам контейнер панели запущенным. Загрузите новую `ValheimAdminRu.dll` на Linux-хост в `/tmp/ValheimAdminRu.dll`. Следующие команды выполняются **на хосте Docker**, а не внутри контейнера. Если сейчас виден prompt `valheim@53d943367fc2`, сначала выполните `exit`.

Найденный у вас каталог выпуска — `/data/releases/plus-f3f61a090eaf4309`. Скопируйте DLL от имени игрового пользователя; так владельцем сразу станет `valheim`, и отдельный `chown` не потребуется:

```sh
taskPluginDir='/data/releases/plus-f3f61a090eaf4309/BepInEx/plugins/ValheimAdminRu'
docker exec -i --user valheim valheim-stack-valheim-1 sh -ec '
mkdir -p "$1"
chmod 755 "$1"
cat > "$1/ValheimAdminRu.dll.tmp"
chmod 644 "$1/ValheimAdminRu.dll.tmp"
mv "$1/ValheimAdminRu.dll.tmp" "$1/ValheimAdminRu.dll"
ls -l "$1/ValheimAdminRu.dll"
' sh "$taskPluginDir" < /tmp/ValheimAdminRu.dll
```

Затем запустите игру кнопкой в Hearth. Права каталога — **755**, DLL — **644**. На компьютерах игроков замените DLL в `BepInEx/plugins/ValheimAdminRu/` и перезапустите Valheim.

После обновления игры или Valheim+ Hearth может создать **новый каталог выпуска**. В таком случае уточните активный выпуск в `/data/state.json` (поле `active`) и скопируйте DLL в `BepInEx/plugins/ValheimAdminRu/` именно нового выпуска. Обычный перезапуск контейнера сохраняет содержимое `/data`.

Предметы и мобы появляются перед персонажем. Поиск работает по русскому названию и внутреннему имени: например, `Wood`, `Troll`, `AdminRu_SuperHammer`. Русские названия читаются из ресурсов игры независимо от выбранного языка Valheim. Для добавленных другими модами объектов используется доступное название; их содержимое должно присутствовать и на сервере.

Радиус операций с землёй, удара и ремонта: **1–40 м**. Высота подъёма или опускания за одно применение: **0,1–8 м**, шаг настройки **0,1 м**. Например, радиус 10 м и высота 2 м поднимут все точки земли внутри круга на 2 м, пока не достигнут предел игры. За одну команду создаётся до **500 единиц предметов** или **20 мобов**. Предметы разбиваются на допустимые игровые стопки. Между ударами супермолота есть задержка в одну секунду, между операциями с землёй — две секунды. Клавиши панели и дополнительного удара меняются в `BepInEx/config/ru.valheim.adminpanel.cfg`, который появится после первого запуска мода. После изменения файла перезапустите игру.

**Поведение, которое важно учитывать**

Все операции с рельефом сохраняются в мире Valheim. Выравнивание использует высоту земли под персонажем, в том числе во время полёта. Подъём и опускание сдвигают текущий рельеф на заданную высоту, сохраняя склоны внутри круга; окраска земли сохраняется. Игра ограничивает изменение высоты **±8 м от исходной поверхности**. Поэтому некоторые точки могут измениться частично или остаться на достигнутом пределе; панель сообщает об этом. Область имеет форму круга; её радиус и площадь показаны в панели. В подтверждении отображаются операция, радиус и высота; изменение параметров отменяет подтверждение.

**Отмена рельефа** хранит один снимок последнего изменения через мод на вашем клиенте в текущем подключении. Следующая операция, реально изменившая землю, заменяет снимок; после переподключения или смены мира он недоступен. Для отмены подойдите к исходной области, чтобы её участки загрузились. Сервер проверяет право на отмену, а клиент сравнивает текущие значения рельефа с сохранённым результатом операции **точно, без допуска округления**. Отличающиеся значения считаются конфликтами и сохраняются, поэтому более поздние правки не перезаписываются.

Уже восстановленные точки удаляются из снимка. Недоступные участки и конфликтующие значения остаются в нём: можно подойти ближе и повторить отмену оставшейся части. Повторная попытка также проверяет совпадение значений и не стирает более поздние изменения. Это отмена одной последней операции, а не история всех изменений мира.

**Очистка спавна** удаляет только вашу последнюю подтверждённую порцию создания объектов в текущем мире. Сервер использует метки владельца, порции и мира. Для предметов проверяются только сетевые объекты, лежащие в мире: инвентари персонажей и контейнеров не сканируются и не изменяются. Если количество в отмеченной стопке изменилось, стопка сохраняется, чтобы не удалить смешавшиеся обычные ресурсы. Обычные немаркированные предметы и мобы также сохраняются.

Удаление сетевых объектов может завершиться позже. Если объекты той же порции ещё остаются или стали доступны позднее, повторите очистку; она повторно проверяет метки и принадлежность порции. Следующий подтверждённый спавн становится новой последней порцией для очистки.

**Точки и возврат.** Именованные точки сохраняются локально в `BepInEx/config/ru.valheim.adminpanel.points.xml` и разделяются по идентификатору мира. Их можно найти, использовать и удалить на вкладке «Точки». Телепорт использует сохранённые координаты с точной высотой, в том числе в подземелье. Точка возврата существует только в текущем подключении: она появляется после телепорта через мод и сбрасывается при отключении или смене мира. Возврат сохраняет предыдущую позицию и направление персонажа.

**Помощь игрокам** восстанавливает здоровье или выносливость либо снимает известные негативные эффекты игры. Положительные и неизвестные эффекты других модов сохраняются. Если причина дебаффа остаётся — например, персонаж стоит в дыму или на холоде, — игра может наложить эффект снова.

**Режим строителя** даёт строительство без расхода ресурсов и отключает износ молота, мотыги и культиватора при работе в этом режиме. Он включается только для своего персонажа после серверной проверки прав. Ремонт — отдельное действие: проверяет доступные повреждённые постройки в **сферическом радиусе** вокруг персонажа, включая постройки выше и ниже него.

**Предпросмотр** показывает круг рельефа, спроецированный на поверхность, и сферическую область удара или ремонта в виде трёх колец. Он включается общим флажком под вкладками. Радиус соответствует выбранной операции; при включённом супермолоте его область остаётся видна и после закрытия панели. Предпросмотр сам не изменяет мир.

Полёт использует встроенное движение Valheim и доступен после серверной проверки прав. Он не включает бессмертие: при выключении полёта возвращается обычная гравитация и персонаж может получить урон от падения. Скорость соответствует встроенному режиму полёта игры, ускорение — в 2,5 раза. Для движения закройте панель. Полёт снова включается после возрождения, если вы оставили режим включённым.

Супермолот повреждает отмеченные группы целей, включая ваши постройки и прирученных мобов, если соответствующие группы включены. Без выбранной группы административный удар недоступен. У оружия модель железной кувалды из игры. При выключенном режиме оно наносит обычный урон этой кувалды. Созданные при разрушении дерева брёвна или новые сегменты залежи руды можно убрать следующим ударом. Значение 999999 задаётся в данных удара до обработки игровых механик и других модов.

Бессмертие, полёт, режим строителя и режим супермолота сбрасываются при отключении, переходе в другой мир или отзыве прав. Предмет супермолота остаётся в сохранении персонажа; для его дальнейшего использования мод должен оставаться установленным.

**Модерация и журнал.** Отключение и блокировка используют серверное соединение выбранного игрока; причина блокировки сохраняется. Снять блокировку можно по записи в списке или полному ID игрока вне сети. Журнал хранит последние **300 записей**, показывает время **UTC**, администратора, действие, параметры и результат. Он сохраняется на сервере в `BepInEx/config/ValheimAdminRu/audit.xml`; в панели доступны обновление и поиск. Серверные роли, причины блокировок и метаданные последней порции спавна также хранятся в XML в каталоге `BepInEx/config/ValheimAdminRu/`.

Для изменения рельефа и его отмены запись «началось» подтверждает запуск операции. Финальный результат и сведения о частично обработанной области появляются в сообщении на клиенте после завершения обработки.

Автоматические проверки используют настоящие исходники мода и подставное игровое окружение. Они проверяют передачу параметров протокола 3 и отклонение предыдущих версий, границы количества, радиуса, высоты и координат, группы целей молота, матрицу прав ролей, источник команд и подтверждений, повторные подтверждения, ограничения модерации, назначение ролей и сброс при отзыве прав или отключении. Используемые сигнатуры методов и полей дополнительно сверены с реальными библиотеками установленной игры.

Отдельно проверены сохранение и разделение точек по мирам, допустимая высота подземелий, данные отмены рельефа и точное обнаружение конфликтов. Проверки полёта и строительства охватывают включение и выключение, права владельца персонажа, отключение, возрождение, отсутствие лишних сетевых записей и сохранение чужого ранее включённого состояния, когда мод его не менял. Расчёты рельефа проверены на сохранение склонов и соблюдение игровых пределов.

Эти проверки выполняют управляемую логику и не запускают Unity. Они не заменяют испытание движения, визуального интерфейса, рельефа, сетевых объектов и Steam-соединения в игре.

Сетевая реализация проверяет права на сервере при каждой команде, использует настоящий источник соединения, проверяет тип создаваемого объекта и принимает подтверждение только от клиента, которому была выдана команда. Это проверка прав функций данного мода; Valheim также имеет собственные действия, выполняемые клиентами.

**Игровой запуск на выделенном сервере ещё не проверен.** Перед использованием в основном мире проверьте мод на копии мира с двумя клиентами: телепорты и возврат, сохранённые точки, помощь второму игроку, спавн и его очистку, рельеф и отмену с более поздними правками, полёт с возрождением, группы целей молота, строительство и ремонт. Проверьте роли владельца, модератора, строителя и обычного игрока, блокировку и снятие блокировки, а также журнал. Для диагностики используется `BepInEx/LogOutput.log` на сервере и клиентах.

**Исходники и повторная сборка**

Исходники находятся в `src/`. Сборка требует .NET SDK, установленной Valheim 1.0.16 или 1.0.17 и BepInEx. Скрипт только собирает DLL в папку внутри этого проекта:

```powershell
.\build.ps1 -ValheimDir 'D:\Games\Valheim'
```

Можно отдельно указать каталоги библиотек игры и BepInEx, например для серверной установки:

```powershell
.\build.ps1 -ManagedDir 'D:\Server\valheim_server_Data\Managed' -BepInExCore 'D:\Server\BepInEx\core'
```

Библиотеки игры и загрузчик BepInEx в архив не включены. После обновления Valheim мод нужно снова проверить и при необходимости пересобрать. Эта версия согласует подключения для игры **1.0.16 или 1.0.17** и мода **0.4.0** (сетевой протокол **4**); версии мода и игры должны совпадать на сервере и клиентах.
