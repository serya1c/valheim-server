# Проверка релиза Hearth 1.5.0 — 8 октября 2026

- Релиз включает слитые PR #10 (модерация, здоровье, расписания), #11 (менеджер модов и обновлённые клиентские установщики) и #12 (документация RU / EN). Версия панели изменена с `1.5.0-dev` на `1.5.0`; функциональный код при подготовке релиза не менялся.
- Для этих изменений ранее прошли 229 серверных тестов, 58 проверок Windows-установщика и 32 теста Linux / Proton. Полный набор при выпуске повторно не запускался.
- В релизном Linux-образе прошли 8 точечных проверок: мастер до настройки, сравнение релизов панели, публичный API, скачивание EXE и SH с проверкой хешей, установка и публикация клиентского набора, приватность модерации и доступность диагностики при ошибке измерений.
- Проверены оба файла Compose и переводы JavaScript. Версия `1.5.0`, новые модули, часовой пояс `Asia/Krasnoyarsk` и контрольные суммы обоих встроенных установщиков проверены внутри образа.
- Чистый контейнер без доступа в интернет отвечает на `/health` и показывает мастер, не скачивая и не запуская игру. Действующий игровой сервер и его данные не изменялись.
- Образ собран с существующим параметром `APT_MAX_FUTURE_TIME=7200`, использованным для локальной среды Docker; значение по умолчанию в Dockerfile остаётся 10 секунд. Проверка подписей и TLS не отключалась.
- README и руководства: 4 документа, 81 локальная ссылка/якорь и 18 JPEG-изображений проверены; обе версии README просмотрены в браузере на демонстрационном стенде.
- Архив проекта формируется из релизного коммита; состав и каждый файл сверяются с Git, контрольные суммы — до и после загрузки assets GitHub. Новые установщики отличаются от v1.4.0 и включают поддержку клиентских наборов модов.
- Полный вход настоящими клиентами Windows / Proton, игровые механики сторонних модов и доставка в живой Discord в рамках этого выпуска не проверялись. Успешный запуск и попытка отката не гарантируют игровую совместимость; Windows EXE пока без подписи издателя.

Ниже — исторические записи предыдущих проверок, относящиеся к указанным датам.

## Linux / Proton — 27 сентября 2026

- Собран отдельный читаемый установщик `Loki-Mod-Installer-Linux.sh` с русским диалогом в терминале; Linux x86_64, Python 3.9+, без sudo. Добавлены кнопка, контрольная сумма, маршрут скачивания и инструкция на лендинге.
- 21 тест Linux-установщика прошёл в Docker: официальный ZIP, Steam/Flatpak, дополнительные библиотеки и ссылки корня, Unicode, отказ для нативной Linux-игры, ссылки внутри установки, регистр имён, ZIP traversal/дубликаты/ссылки, резервная копия, сохранение конфигураций, восстановление, откат после частичной записи, изменённые после установки файлы, прерванная установка, повторная установка, блокировка, запущенная игра, ошибки версии и SHA-256, конфликт BepInEx 6.
- Самостоятельный скачиваемый SH запущен в Linux-контейнере с `--launch-options`; корректно показал инструкцию Proton.
- Из Linux-контейнера успешно прочитан действующий https://loki.ach-play.ru/api/public: Valheim 1.0.15, V+ 0.10.2.0. Тем же сетевым кодом загружен официальный WindowsClient.zip (837068 байт), SHA-256 подтверждён.
- Docker-образ пересобран. 65 серверных тестов прошли, включая загрузку обоих установщиков и совпадение SHA-256.
- Локальная страница проверена в браузере: кнопки Windows / Linux и ссылка инструкции присутствуют, оформление без наложения.
- Реальная игра через Proton не запускалась: графического Steam-клиента Linux в тестовой среде нет. Перед массовым распространением нужна проверка входа игрока с Linux-компьютера.
- Изменения подготовлены локально, на публичный сервер не развёрнуты. Параметры Steam и реальные пользовательские игры не изменялись.

## Установщик Windows — 25 сентября 2026

- Собран самостоятельный Windows x64 EXE на .NET 10 / WinForms, 51,7 МБ. Сборка без предупреждений и ошибок; проверка создания окна из опубликованного EXE завершилась с кодом 0.
- 29 проверок логики прошли на Windows: библиотеки Steam и Unicode-пути, версия сервера, отказ при неизвестной версии, SHA-256, соответствие DLL, небезопасные пути/архивы, сохранение конфигураций и посторонних файлов, резервная копия, ручной и автоматический откат, защита от перезаписи последующих изменений и дубликатов V+.
- Использован настоящий официальный WindowsClient.zip 0.10.2.0. Загрузка через сетевой клиент установщика из GitHub с HTTPS и проверкой SHA-256 дала байт-в-байт тот же пакет.
- Docker-образ пересобран; 64 теста прошли внутри Linux-контейнера, включая публичную раздачу EXE и совпадение опубликованной контрольной суммы.
- В браузере проверена кнопка на лендинге и оформление блока подключения. Предпросмотр оставлен открытым.
- Полный проход через графическое окно с реальной Steam-установкой и вход игрока не выполнялись. Запись и откат проверены на временном макете каталога игры. Работа с реальным доменом Loki потребует развёрнутого сайта и установленного сервера, сообщающего версии через /api/public.
- EXE не подписан сертификатом издателя.

- Проверено покрытие русскими пояснениями всех 470 параметров фактического CFG. Добавлена проверка извлечения комментариев отдельно от типов, диапазонов и значений по умолчанию.

- Проверены синтаксис трёх JavaScript-файлов и конфигурация Docker Compose.
- SteamCMD действительно скачал сервер из public-ветки, build 25390671. Исправлена команда загрузки: обновление сведений о приложении перед установкой, без лишнего выбора ветки public.
- Официальный UnixServer.zip Grantapher 0.10.2.0 проверен по SHA-256: `4f990653dba255cacd13f60c08fc17dc0cde0fb90f200743ecb90593d34070c2`.

## Границы проверки

- Игровой клиент не подключался. Поведение изменённых параметров непосредственно у персонажа, реальные подключения/отключения и статистика игроков не проверены.
- На закрытом сервере (`SERVER_PUBLIC=0`) A2S не ответил. Панель показывает неизвестный онлайн; успешный ответ A2S и имена игроков не подтверждены.
- Полный автоматический цикл первоначальной установки после исправления SteamCMD не повторялся целиком: загрузка, распаковка, проверка кандидата и запуск выполнены последовательно в тестовой среде. Транзакции обновления и отката дополнительно покрыты тестами с имитацией загрузчика.
- Crossplay не включён. В headless-логе присутствовали сообщения о шейдерах и отсутствии libParty.so; они не помешали Steam-серверу дойти до состояния подключения.
- При сборке индекс репозитория Debian имел дату на несколько часов вперёд относительно часов Docker. Для проверочного образа использован `APT_MAX_FUTURE_TIME=14400`; подписи и TLS не отключались. Обычный Dockerfile сохраняет допуск 10 секунд.

Перед переносом своего основного мира проверьте вход совместимым клиентом, сохранение и восстановление копии на новом тестовом мире. Сохраняйте исходные файлы до завершения этой проверки.
